## 🛠️ Quick Start (Task 1)

To run and preview **Task 1** locally:

### Option 1: Using Node.js
```bash
cd "Task 1"
node serve.js
```
Then open [http://localhost:3000](http://localhost:3000) in your browser.

### Option 2: Open directly
Open `Task 1/index.html` directly in any web browser, or use VS Code's **Live Server** extension.

---

## 🛠️ Quick Start (Task 3 - GitBoy)

To run **Task 3** locally:

```bash
cd "Task 3"
npm install
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser. Live deployment: [https://git-boy.vercel.app/](https://git-boy.vercel.app/)
