# Task 1: InAmigos Foundation Responsive Website

A responsive, accessible web portal designed and developed for **InAmigos Foundation** — a Section 8 registered NGO working across India in education, hunger relief, animal welfare, women empowerment, and environmental sustainability.

---

## 🌟 Key Features

- **Dynamic Modern UI/UX**: Custom color scheme aligned with InAmigos Foundation branding, clean typography, smooth transitions, and responsive layout.
- **Accreditations & Trust**: Prominently highlights NGO certifications (80G & 12A, CSR-1, and NITI Aayog Darpan registered).
- **Core Initiatives / Causes**:
  - *Siksha Jyoti*: Underprivileged child education & digital literacy.
  - *Feed the Hungry*: Daily nutrition & food distribution drives.
  - *Paws & Claws*: Street animal rescue, veterinary care, and feeding.
  - *Empower Her*: Vocational training & women empowerment.
  - *Green Earth*: Afforestation and environmental sustainability drives.
- **Interactive Modals**:
  - **Volunteer Registration Form**: Full volunteer onboarding interface with areas of interest.
  - **Online Donation Form**: Secure-styled donation flow with PAN number input for 80G tax exemption.
- **Live Counters & Impact Metrics**: Demonstrates quantified achievements (meals served, students educated, trees planted, animals treated).
- **Zero-Dependency Local Server**: Built-in `serve.js` script to run the static site locally without any `npm install`.

---

## 📁 Files in this Directory

- `index.html`: Complete single-page application structure, styling, and interactivity.
- `serve.js`: Node.js lightweight static server.
- `assets/logo.jpg`: High-resolution InAmigos Foundation logo.
- `assets/logo-cropped.png`: Transparent cropped icon used as navbar branding & favicon.

---

## 💻 How to Run Locally

### Option A: With Node.js
```bash
node serve.js
```
Navigate to `http://localhost:3000` in your web browser.

### Option B: Directly in Browser
Double-click `index.html` or open it with any web browser.
